# PLP Python Week 7

This repo shows file handling in Python.

## Files
- my_notes.py - writes, appends and reads my_notes.txt
- my_notes.txt - sample notes file
- hubs.csv - sample learner data
- report_builder.py - reads hubs.csv and writes report.txt
- report.txt - output report

## How to run
python my_notes.py
python report_builder.py
